# dsh_session_delete

在左侧会话的「…」菜单添加「删除此对话」，二次确认后删除本地会话记录。

适配 DSH **0.2.0-rc.2** 的 JSONL 存储。使用 DSH 原有菜单、弹窗与带认证的 API，不需要构建步骤或额外依赖。

## 安装

```powershell
dsh plugin --profile web add github:lvzhiyuan0308/dsh_session_delete
```

安装后重启 DSH，再刷新页面。点击会话「…」→「删除此对话」→「删除」。取消或关闭弹窗不会删除。

## 实现边界

- 只删除所选会话，停止其运行工作并等待会话写入关闭；不删除工作目录、其他会话或共享附件。
- 清理工作区会话关联、置顶及归档标记，并通知客户端移除条目；搜索索引通过 DSH 的下次查询自动同步。
- 会话目录保留 DSH 的 `session.lock` 空锁文件，避免与其他进程争用同一个锁；对话日志及历史格式文件会删除。
- rc.2 没有公开的删除/释放接口，因此后端使用其 `agentLoop.prepare` 获取正常生命周期释放函数，以及 JSONL 文件定位和锁接口。升级 DSH 后需重新验证这几个接口。
- 插件启用前已加载的会话需要重启 DSH 后才能删除，以保证有正确的生命周期释放函数。

核心代码只有 `index.js`（后端）和 `client.js`（前端）。
